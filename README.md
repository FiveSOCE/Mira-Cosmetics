# MiraCosmetics

Cosmetic unlock and effect framework for Paper 1.21.11 / Java 21.

## Current release

**v0.1.0**

Direct download:
https://github.com/FiveSOCE/Mira-Cosmetics/releases/download/v0.1.0/MiraCosmetics-0.1.0.jar

All releases:
https://github.com/FiveSOCE/Mira-Cosmetics/releases

## Features

- Persistent cosmetic unlocks and equipped slots
- Generic cosmetic registry API
- Trail cosmetics
- Join effects
- Kill effects
- Admin grants
- Built-in flame/heart trails, totem join effect and soul-fire kill effect
- Public Bukkit ServicesManager API for future Crates, Daily and Seasons rewards

## Commands

- `/cosmetics list`
- `/cosmetics equip <id>`
- `/cosmetics clear <trail|join|kill>`
- `/cosmetics grant <player> <id>`

## Build

`./gradlew build`

Output: `build/libs/MiraCosmetics-0.1.0.jar`
